# Streamlit Exploration App

**Module:** 6 — Web Essentials & Streamlit
**Estimated time:** 30 minutes

## Objective

Build an interactive Streamlit app that demonstrates at least five different widget types and responds dynamically to user input.

## What You'll Build

A "Python Learning Journey" app that uses Streamlit's re-run model. Each widget interaction re-executes the entire script, so content updates automatically. You will use at least five widget types — including `st.slider()`, `st.selectbox()`, `st.radio()`, `st.multiselect()`, `st.text_input()`, and `st.checkbox()` — and display content that changes based on their current values.

## Reference Code

The starter file (`starter.py`) provides a scaffold with TODOs — fill in each section, then compare with the solution.

## Running

```bash
streamlit run starter.py
```

## Deliverable

A Streamlit app using 5+ widget types where displayed content changes based on widget values.
