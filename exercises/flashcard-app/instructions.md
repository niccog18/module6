# Interactive Flashcard App

**Module:** 6 — Web Essentials & Streamlit
**Estimated time:** 30 minutes

## Objective

Build a single-page flashcard app using HTML, CSS, and vanilla JavaScript to practice DOM manipulation and event handling.

## What You'll Build

A flashcard application in a single HTML file. It contains an array of 5 question-and-answer pairs covering web development topics (HTTP methods, CSS selectors, DOM, status codes, async/await). The app displays the current question, provides a "Show Answer" button to toggle answer visibility, a "Next" button to advance cards, a progress indicator ("Card X of 5"), and loops back to card 1 after the last card. Key JavaScript concepts include `querySelector()`, `addEventListener()`, `textContent`, and `style.display`.

## Reference Code

The solution file (`flashcards.html`) is provided as a reference — try building it yourself first, then compare.

## Running

Open `flashcards.html` directly in your browser.

## Deliverable

A single HTML file with a working flashcard app that cycles through 5 Q&A pairs.
