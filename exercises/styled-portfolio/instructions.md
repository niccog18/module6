# Styled Portfolio

**Module:** 6 — Web Essentials & Streamlit
**Estimated time:** 20 minutes

## Objective

Apply CSS classes to an HTML portfolio page so that an external stylesheet can target and style the elements.

## What You'll Build

Starting from a provided HTML structure, you will add CSS class attributes to elements so they match the selectors defined in `styles.css`. Classes to assign include `.site-header`, `.header-content`, `.tagline`, `.main-nav`, `.content-wrapper`, `.project-grid`, `.project-card`, `.project-module`, and `.site-footer`. You will also link the stylesheet using a `<link>` tag. The goal is to understand how CSS selectors connect to HTML elements.

## Reference Code

The solution files (`portfolio.html` and `styles.css`) are provided as a reference — try building it yourself first, then compare.

## Running

Open `portfolio.html` directly in your browser. Verify that styles from `styles.css` are applied correctly.

## Deliverable

An HTML file with the correct CSS classes assigned to each element and a linked stylesheet producing a styled portfolio page.
