# Semantic Portfolio Page

**Module:** 6 — Web Essentials & Streamlit
**Estimated time:** 20 minutes

## Objective

Build a personal portfolio page using HTML5 semantic elements to practice meaningful document structure.

## What You'll Build

A portfolio page that uses semantic HTML elements for structure and accessibility. Use `<header>` for the site header with your name and navigation, `<nav>` for navigation links, `<main>` for primary content, `<section>` for thematic groups with headings, `<article>` for each self-contained project entry, and `<footer>` for closing info. No CSS is needed — the focus is on structure and meaning. Every `<img>` must include an `alt` attribute.

## Reference Code

The solution file (`portfolio.html`) is provided as a reference — try building it yourself first, then compare.

## Running

Open `portfolio.html` directly in your browser.

## Deliverable

A single HTML file using semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`) to structure a portfolio page.
