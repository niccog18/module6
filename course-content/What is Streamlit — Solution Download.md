# What is Streamlit? — Solution Download

**GitHub:** `module-06-web-streamlit/solutions/exercises/exploration-app/`

The reference solution builds a trip planner app. Your solution will be different (and that’s the point!). Key things to check:

- Do you have at least 5 different widget types?
- Does content visibly change when you interact with widgets?
- Is there at least one calculation using widget values?
- Does the app run without errors with `streamlit run explore.py`?

Don’t worry about layout or visual polish yet — that’s the next lesson.
