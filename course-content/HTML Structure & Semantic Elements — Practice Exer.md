# HTML Structure & Semantic Elements — Practice Exercise

## Build Your Portfolio Page

**Objective:** Create a semantic HTML page from scratch, reinforcing your understanding of document structure and meaningful element choices.

**Time:** 25 minutes

**What you'll do:**

1. Create a new file called `portfolio.html`
2. Start with the full HTML skeleton (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
3. Build a portfolio page with the following structure:

**Header:**

- Your name as an `<h1>`
- A short tagline (e.g., "Aspiring AI Engineer")
- A `<nav>` with links to the sections below (use `#id` anchor links)

**Main content with three sections:**

- **About section** (`<section id="about">`): A paragraph about yourself or a fictional character transitioning into tech
- **Projects section** (`<section id="projects">`): Three project entries, each as an `<article>` with an `<h3>` title and `<p>` description. Use projects from modules you've already completed (Grade Tracker, Data Pipeline, Task Manager API) or make up relevant ones.
- **Skills section** (`<section id="skills">`): An unordered list (`<ul>`) of at least 5 skills

**Footer:**

- A contact email as a link (`<a href="mailto:...">`)
- A copyright line using `&copy;`

**Deliverable:** A `portfolio.html` file that opens in a browser and displays a structured, semantic page. The page will look plain (no styling yet) — that's expected!

**Why this exercise?** You're building a real portfolio page that you'll style with CSS in the next lesson and could eventually expand into a personal site. The content mirrors your actual course progress, making it both a learning exercise and a useful artifact.
