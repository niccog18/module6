# Streamlit Layout & Components — Solution Download

**GitHub:** `module-06-web-streamlit/solutions/exercises/personal-dashboard/`

The reference solution builds a study progress dashboard. Your topic and data will be different. Key things to check:

- Does `st.set_page_config()` appear before any other `st.` calls?
- Are sidebar controls actually affecting the main content?
- Do your metric cards display in a row (using `st.columns`), not stacked vertically?
- Do your tabs show different content when clicked?

Layout and design choices are subjective — the important thing is that the structural components are used correctly.
