# HTML Structure & Semantic Elements — Solution Download

**GitHub:** `module-06-web-streamlit/solutions/exercises/portfolio-page/`

Compare your solution to the reference. Key things to check:

- Does your page start with `<!DOCTYPE html>` and include a proper `<head>` with `<meta charset>` and `<title>`?
- Did you use semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) rather than only `<div>` tags?
- Do your anchor links (`<a href="#about">`) match the `id` attributes on the corresponding sections?

Differences in content, wording, and extra elements are completely fine — the important thing is the semantic structure.
