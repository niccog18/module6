# Module 6: Web Essentials & Streamlit

**Duration:** 2 Weeks | **Hours:** 40

**Philosophy:** Week 1 gives web literacy — HTML structure, CSS basics, JavaScript interactivity, and how the browser communicates with servers. Week 2 gives Streamlit — the Python-native UI tool students will use to build AI interfaces for the rest of the course. By the end, students have a running Streamlit app connected to their Module 5 FastAPI backend with at least one AI-powered feature.

---

## Lessons

### Week 1 — Web Literacy

1. How the Web Works (DNS, HTTP, Client/Server)
2. HTML Structure & Semantic Elements
3. CSS Essentials (Selectors, Box Model, Flexbox)
4. JavaScript Basics (Variables, Functions, DOM)
5. Fetch API & Async/Await
6. Connecting Frontend to Backend

### Week 2 — Streamlit

1. What is Streamlit? (Python-Native UI)
2. Streamlit Layout & Components
3. User Input, Forms & State Management
4. Displaying Data: Tables, Charts, Metrics
5. Connecting Streamlit to FastAPI
6. Building an AI-Powered Interface

## Assessments

- **Knowledge Check:** Web & UI Fundamentals Check (end of Week 1 / start of Week 2)
- **Module Project:** AI Dashboard (5-minute presentation)
